# ChatXP Android 登录/注册开发计划

> 开发版本：`v1.2.0-dev`<br>
> 后端计划：[`../backend/02-login-registration-plan.md`](../backend/02-login-registration-plan.md)

## 1. 功能范围

- 登录不是使用 App 的前置条件，游客可直接聊天。
- 游客可注册新账号或登录已有账号，并保留登录前会话。
- 登录状态跨启动保持；每次冷启动仍进入新的空白对话。
- 支持当前设备退出登录，退出后立即切换为新游客。
- 不实现邮箱验证、忘记密码、资料编辑、多账号快捷切换和账号注销。

参考图只约束页面布局和控件顺序；颜色、字体、圆角、间距、按钮、输入框、错误态及明暗主题全部使用当前 Compose设计系统。

## 2. 导航与入口

- 根导航包含 Chat 与 Auth 两个目的地。
- 游客侧边栏底部显示现有 `tourist` 图标，点击进入 Auth并默认选择登录 Tab。
- 登录用户头像显示服务端 `avatar_text`。
- 登录头像点击打开账号面板，展示用户名、邮箱和“退出登录”。
- Auth返回操作回到原游客聊天，不修改身份或会话。
- 登录、注册或退出成功后都返回新的空白对话。

## 3. 登录页面

控件顺序：欢迎标题、登录/注册切换、邮箱、密码与显隐按钮、登录按钮、忘记密码、协议提示。

- 邮箱和密码必填。
- 提交时禁用重复操作并显示加载状态。
- 凭证失败统一显示“邮箱或密码错误”。
- 忘记密码只提示“暂未开放”，不调用接口。

## 4. 注册页面

控件顺序：标题、登录/注册切换、用户名、邮箱、密码、确认密码、创建账户按钮、协议提示。

- 用户名 trim后 1–30 字符，不要求唯一。
- 邮箱 trim后进行格式检查。
- 密码为 8–72 字符，不增加组合复杂度要求。
- 确认密码只在本地比较，不发送服务端。
- Tab切换时保留邮箱，清空密码、确认密码和旧错误。
- 注册成功即进入登录状态，不要求验证码。

## 5. 状态管理

Auth ViewModel独立维护：当前 Tab、各字段、密码显隐、字段错误、提交状态和全局错误。

统一身份状态：

```text
Initializing → Guest → Registered
                       └─ logout → Guest（新游客）
```

- `AuthRepository` 提供 `me`、`register`、`login`、`logout` 和 token刷新。
- token、过期时间与 AuthUser必须原子写入 DataStore。
- 注册成功保留原游客 user ID；登录成功由后端合并游客会话。
- 成功切换身份后清除旧会话缓存并重新加载侧边栏。
- 退出后清除账号缓存、选中会话和活动请求，保存服务端返回的新游客。

## 6. 头像和账号面板

- `account_type=guest` 时只显示 tourist drawable。
- `account_type=registered` 时显示 `avatar_text`；拉丁字母大写，汉字保持原样的规则由服务端统一计算。
- 账号面板只展示 `display_name`、`email` 和退出按钮。
- 退出操作需要二次确认。
- 活跃回复期间登录、注册或退出收到 `AUTH_TRANSITION_BUSY` 时，提示等待回复完成。

## 7. 接口映射

- 初始化：`POST /auth/anonymous`
- 当前用户：`GET /auth/me`
- 注册：`POST /auth/register`，发送用户名、邮箱、密码。
- 登录：`POST /auth/login`，发送邮箱、密码。
- 退出：`POST /auth/logout`，成功响应直接包含新游客身份和 token。
- 刷新：`POST /auth/refresh`

错误映射：

- `INVALID_CREDENTIALS`：邮箱或密码错误。
- `EMAIL_ALREADY_REGISTERED`：提示切换到登录 Tab。
- `LOGIN_RATE_LIMITED`：提示稍后重试。
- `AUTH_TRANSITION_BUSY`：提示等待当前回复完成。
- `ALREADY_AUTHENTICATED`：刷新身份并返回聊天。

## 8. 适配和无障碍

- 页面内容可滚动，软键盘不能永久遮挡主按钮。
- 支持浅色、暗色和小屏。
- 输入框提供正确键盘类型、IME动作、内容描述和错误语义。
- 密码默认隐藏，显隐按钮状态和内容描述同步变化。
- 所有可点击文本满足最小点击区域要求。

## 9. 测试与验收

- 游客图标和登录文字头像展示正确。
- 登录/注册 Tab切换和字段保留规则正确。
- 表单校验、密码显隐、加载和错误提示正确。
- 忘记密码不产生网络请求。
- 游客注册后原会话仍在侧边栏。
- 游客登录已有账号后同时看到账号历史和游客会话。
- 退出后进入新游客，账号会话不再显示。
- 退出期间的新游客会话在再次登录后被合并。
- App重启保持账号身份但主界面仍为新对话。
- 浅色、暗色、小屏和软键盘场景通过界面验收。
