# ChatXP Android 模型与思考程度切换计划

> 开发版本：`v1.3.0-dev`<br>
> 后端对应计划：[`../backend/03-model-switching-plan.md`](../backend/03-model-switching-plan.md)

## 1. 目标

在聊天页内快速切换模型和思考程度，不跳转新页面。默认配置为“5.5 + 标准”，配置按会话保存并只影响后续回复。

## 2. 菜单与交互

- 点击模型配置按钮后，在按钮附近直接展开小型浮层菜单。
- 菜单上半部显示模型 `5.5`、`5.6`，下半部显示思考程度“标准”、“进阶”。
- 两组选项各自单选，当前选项右侧显示勾选，不使用单独确认按钮。
- 选择后立即更新勾选且菜单保持展开，便于连续调整两组选项。
- 点击菜单外部、再次点击配置按钮或离开聊天页时关闭。
- 颜色、字体、间距、圆角、勾选图标和明暗主题均使用项目现有设计系统。

## 3. 状态与数据流

- `ModelOption` 接收公开模型 ID、显示名和支持的 `reasoning_modes`；客户端不感知 Flash、Pro 或供应商模型名。
- `ChatUiState` 增加当前模型、当前 `reasoning_mode`、菜单展开状态和配置更新状态。
- 新 draft 初始为 `chat-5.5 + standard`；切换时只更新本地状态，首次发送时一并提交。
- 打开已有会话时以服务端 `Session` 为准；选择新项后调用会话 PATCH。
- PATCH 成功后保留新选择；失败时回滚该组选项，保留另一组已成功的配置并显示错误。
- 配置请求期间禁用重复点击；已经运行的生成任务不因菜单切换而改变。

## 4. 异常与兼容

- 模型目录加载失败时显示“5.5 + 标准”，但禁用未被当前目录确认的选项。
- 模型被服务端移除或返回 `MODEL_NOT_FOUND` 时，刷新目录并回退至“5.5 + 标准”。
- 未知的思考程度不导致页面崩溃；以“标准”显示并记录契约异常。
- 本期不展示供应商、价格、上下文长度、延迟或“自动选择”。

## 5. 测试与验收

- 新对话默认勾选 5.5 和标准，模型和思考程度可独立切换。
- 菜单的定位、分组、勾选、关闭、滚动边界、软键盘和明暗主题表现正确。
- draft 首条消息携带所选配置，已有会话切换后只影响后续回复。
- PATCH 失败会回滚对应选项，快速重复点击不会造成状态乱序。
- 四种模型与思考程度组合均能正确发送、恢复和展示。
